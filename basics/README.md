# C++ Basics

This folder contains small programs for learning C++ syntax and fundamentals.

## Topics to add
- Output and input
- Variables and data types
- Operators
- If/else and switch
- Loops
- Functions
- Arrays and strings

## Current example
- [Hello World](hello_world.cpp)

Compile from the repository root:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic basics/hello_world.cpp -o hello_world
```
