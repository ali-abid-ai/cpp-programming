# Object-Oriented Programming

This folder contains examples that introduce classes, objects, data members, and member functions.

## Current example
- [Student Record](student_record.cpp) — a small class with private data and a public display method.

## Next topics
- Constructors and destructors
- Encapsulation
- Inheritance
- Polymorphism
- Function and operator overloading

Compile from the repository root:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic oop/student_record.cpp -o student_record
```
